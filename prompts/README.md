# Промпты

Производный раздел. Промпты составляются только из уже размеченной базы.

## План

- восстановление контекста в новом чате;
- стилизация короткой записи;
- длинный обзор;
- диалог Алекса, Игоря и Сергея;
- генератор сюжетов;
- проверка узнаваемости;
- промпт для изображения;
- контроль визуальной непрерывности;
- запрет на превращение сатиры в факт.

Промпт всегда должен указывать эпоху, жанр, степень карикатурности и разрешённый слой канона.
