# Источники раздела
55 исходных авторских публикаций; 81 уникальный URL во всех карточках. Это число ссылок, не число независимых свидетелей. Первичные личные истории обычно подтверждены только словами самого автора.
Публикации из БД проверялись по сохранённому `body`, а исправления — также по сохранённому HTML. Для 25 выбранных постов дополнительно получены полные HTML и контексты комментариев. В HTML цитату читателя отделяли от собственного ответа автора; ссылка в карточке ведёт на фактический адрес комментария, включая `/comments/` там, где он используется.
Для новых публикаций после окончания БД использованы страницы действующего сайта. Культ служит указателем и источником рецепции; цитаты Культа не считаются независимым подтверждением описываемых им событий. Неолурк прочитан тематически с переходом к доступному первоисточнику DealExtreme.
