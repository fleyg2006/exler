# Произведения и публикации

## Реестр

- художественные книги;
- компьютерные книги и руководства;
- кинорецензии;
- обзоры техники;
- записи о еде и вине;
- путевые заметки;
- общественно-политические записи;
- видео, эфиры и интервью;
- публикации в социальных сетях.

Для каждой работы: дата, жанр, краткий конспект, темы, характерные фразы, персонажи, достоверные цитаты и влияние на общий образ.
