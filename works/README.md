# Публикации как материал для пародии

## Наши готовые тексты

- [Долговечный вердикт](parodies/durable-verdict.md) — бритва и неизнашиваемое мнение о ней.
- [Независимость от розетки](parodies/socket-independence.md) — инфраструктура для избавления от лишних проводов.
- [Пенсия для декантера](parodies/decanter-retirement.md) — исправная вещь, которая устарела эстетически.

Это пародии, не публикации Экслера. Фактическая основа и вымысел разделены в примечаниях к каждому тексту.

Из каждой выбранной работы извлекаем композицию, вердикт, речевой приём и сцену, которую можно комически развить. Полный библиографический каталог не является условием для написания шуток.

Приоритет — товарные посты, технообзоры, кинорецензии, бытовые заметки и публичные ответы автора. Книги разбираем отдельно: реплика литературного персонажа не равна мнению писателя.

Карточка произведения: название, дата, ссылка, жанр, краткая фактическая основа, приём рассказчика, возможная пародия, связанные мемы. Готовый корпус покупок описан в [исследовании](../research/products/PRODUCT_RANKING.md).
