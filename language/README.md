# Как устроена узнаваемая пародия

[Манера письма](style.md) задаёт композицию. [Разбор товарных постов](../research/products/STYLE_FINDINGS.md) связывает её с эпизодами. [Промпт пародии](../prompts/parody.md) помогает собрать готовый текст.

Сначала повторяем ход рассказа: ничтожная задача, обстоятельная предыстория, перечисление параметров, личное испытание, уверенный вердикт. Затем добавляем одно осложнение и один-два речевых маркера. Перечень мемных слов сам по себе ещё не пародия.

Различаем реально подсчитанные маркеры, словарь из Неолурка и наши вымышленные реплики. «Обзор будет» в нашем каноне не становится автоматически частотной цитатой из корпуса.

Каждый новый языковой приём сохранять с примером, датой и жанром. Обещанные, но ещё не созданные словари и исследования эпох не перечисляем как готовые материалы.
