# Язык и авторская манера

## Подразделы

- `lexicon.md` — слова и устойчивые выражения с частотой и примерами.
- `syntax.md` — длина фраз, скобки, тире, перечисления и вводные конструкции.
- `composition.md` — устройство заметки, обзора, рецензии и жалобы.
- `tone.md` — уверенность, снисходительность, раздражение, восторг.
- `humor.md` — собственные приёмы юмора.
- `eras.md` — различия между ранним, средним и нынешним Экслером.
- `quotes.md` — только проверенные дословные цитаты.
- `imitation-rules.md` — правила убедительной стилизации.

Главная задача — моделировать ход текста, а не просто рассыпать «что характерно» через предложение.
