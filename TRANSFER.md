## Шлюз

Адрес: https://exler.tech/exler_archive_gateway.php
Доступ: заголовок X-API-Key. Токен получить отдельно у владельца, в GitHub не сохранять.
Подключение сервера: соседний db.php, переменные $db (mysqli) и $db_name. Данные остаются в MySQL.

GET action=stats — фактические количества и диапазоны дат.
GET action=posts&limit=250&include_body=1 — посты; следующая страница через after_id=next_after_id.
GET action=alex_comments&limit=250 — комментарии автора Alex Exler; тот же курсор.
GET action=post&id=N — пост и ограниченная первая порция комментариев.
GET action=comments&post_id=N&limit=250 — комментарии поста; продолжение через after_id.
GET action=word_counts&scope=alex&limit=250 — верхушка частотного словаря комментариев, не всего авторского корпуса.
HTML доступен через include_html=1, запрашивать точечно.

## Ограничения данных

ID не соответствует хронологии. Для анализа использовать даты публикаций. Комментарии могут содержать цитаты чужих реплик; их нельзя считать словами Алекса. В схеме нет parent_id: отношения ответов необходимо восстанавливать из HTML. Пустой body комментария может соответствовать изображению. Ошибки извлечения не равнозначны отсутствию исходного HTML. Все частоты нужно проверить на дубли, цитаты и полноту обработки; сравнение с прочими авторами пока не выполнено.

Следующий этап — выгрузка и аудит корпуса, затем доказательные карточки с URL, post_id, comment_id, датой и типом утверждения.
