# Повадки как комические сценарии

Единица наблюдения — действие: выбрал, заказал, похвалил, столкнулся с осложнением, нашёл следующее решение. Для одного эпизода достаточно одной ссылки; для устойчивой повадки нужны несколько независимых примеров и контрпримеры.

| Сценарий | Где искать | Как превращать в сцену |
|---|---|---|
| Упростить быт новой покупкой | Истории аккумуляторов | Для избавления от проводов оборудуется зарядная станция |
| Обосновать смену вещи | Декантеры | Исправный предмет проходит комиссию по моральному старению |
| Сохранить вердикт после осложнения | Бритвы | Положительная оценка переживает замену головки |
| Управлять дискуссией | [Правила площадки](control-and-boundaries.md) | Обсуждение свободно в пределах инструкции хозяина |

Правая колонка — вымышленные сценические решения, не описания реальных событий. Для разработки использовать [карточки](../research/products/SATIRE_CARDS.md).
