# Темы, вещи и реквизит

Собираем то, вокруг чего удобно строить сатирическую сцену: гаджет, цена, способ использования, уверенный вывод и новое осложнение.

| Тема | Комическая задача | Материал |
|---|---|---|
| Китайские покупки | Показать повтор, накопление, перемену аргумента | [Подсчёты](../research/products/PRODUCT_RANKING.md) |
| Вино и декантеры | Придать бытовому выбору масштаб экспертного решения | [Истории](../research/products/PURCHASE_STORIES.md) |
| Чтение и техника | Перевести личное удобство в прогноз для всего мира | [Чтение и устройства](reading-and-devices.md) |
| Кино, еда, поездки | Найти конкретный вердикт и смешное следствие | Новые карточки по датированным публикациям |

Название темы ещё не доказывает увлечение или привычку. Частота слова не равна числу покупок. На AliExpress и другие товарные карточки не переходим: для этого исследования используем авторские тексты и сохранённые данные.
