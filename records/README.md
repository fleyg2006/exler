# Карточки: от эпизода к шутке

Одна карточка — один наблюдаемый эпизод или одна проверенная цепочка. Формат — [SCHEMA.md](../SCHEMA.md).

- [Декантер, который устарел](decanter-retirement.md).
- [Бритва и долговечный вердикт](shaver-verdict.md).

Карточка хранит фактуру отдельно от комического механизма, сцены и вымышленной реплики. Число повторов брать из проверенных событий, а не из количества ссылок. По карточке должно быть возможно открыть исходную публикацию и понять, какую часть придумали мы.
