# Атомарные записи

Здесь будут храниться машинно-читаемые карточки отдельных наблюдений по схеме из `SCHEMA.md`.

## Пространства идентификаторов

- `bio.*`
- `personality.*`
- `behavior.*`
- `interest.*`
- `language.*`
- `relationship.*`
- `event.*`
- `meme.*`
- `visual.*`
- `source.*`

Карточка должна быть маленькой: один тезис, его доказательства, период, уверенность, связи и способ применения в сатире.
