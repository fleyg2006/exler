# Источники фактуры и сатирической оптики

Для каждой работы над образом сначала читать [сохранённую выжимку Неолурка](neolurk-summary.md), затем [наш канон](../canon/our-canon.md). Это обязательный контекст проекта.

У источников разные функции:

- Собственные публикации Экслера дают точные слова, даты, рекомендации и сообщения о личном опыте.
- Неолурк даёт историю мемов и карикатурный образ. Сведения о чтении оригинала и ограничения указаны в самой выжимке.
- Культ Экслера даёт сатирические наблюдения и сюжеты. Для конкретного вывода нужна ссылка на запись; ссылка на главную страницу не доказывает изучение нескольких месяцев.
- [Корпус базы](database-corpus.md) позволяет искать и считать; его полнота и ошибки учитываются отдельно.

Не переносить чужую оценку в колонку фактов. Сохранять URL, дату, автора источника, тип утверждения и место нужного фрагмента. В рамках разбора покупок не открывать AliExpress, его короткие ссылки или перенаправления к карточкам. Названия и параметры берём из сохранённых постов, не уточняем догадкой по магазину.
