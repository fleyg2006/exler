# Источники

## Приоритет

1. Собственные датированные публикации и книги Экслера.
2. Его видео, интервью и публичные аккаунты.
3. Архивные копии удалённых или изменённых публикаций.
4. Надёжные независимые публикации.
5. Форумные обсуждения и воспоминания.
6. Сатирические вики и мемные архивы.

## Для каждого источника

URL, автор, дата публикации, дата доступа, тип, надёжность, краткий конспект, извлечённые наблюдения, сомнительные места и локатор цитат.
