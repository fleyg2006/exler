# Хронология вердиктов и повторов

Сопоставляем датированные заявления: что рекомендовал, что заказал, как оценил после использования и что написал позднее. Это позволяет строить шутку на развитии сюжета, а не придумывать перемену мнения.

- [История сайта](site-history.md) — исторический фон авторской роли.
- [Истории покупок](../research/products/PURCHASE_STORIES.md) — готовые цепочки товаров.
- [События по моделям](../research/products/data/model_events.json) — даты, ссылки и роли упоминаний.

Временная цепочка хранит обе версии при расхождении. Две похожие вещи не объединяются в один физический экземпляр без основания. Неизвестные даты остаются неизвестными; ID базы не заменяет календарную дату.
