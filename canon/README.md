# Канон проекта

## Три слоя

1. **Исторический сетевой канон** — реально существовавшие мемы Рунета.
2. **Наблюдаемый авторский канон** — повторения в собственных публикациях Экслера.
3. **Наш вымышленный канон** — 25:00, гиперболизированные гаджеты, ВПБ и другие внутренние шутки.

У каждого элемента должны быть происхождение, дата первого обнаружения, варианты, визуальные признаки, совместимые сюжеты и запреты. Слои нельзя выдавать друг за друга.
