# Канон узнаваемой сатиры

| Слой | Источник | Применение |
|---|---|---|
| Сетевые мемы | [Неолурк](../sources/neolurk-summary.md) | Экспертная поза, «двепицот», знакомые пацаны |
| Наблюдаемые эпизоды | Собственные публикации автора | Конкретная покупка, срок, цена, вердикт |
| Наш вымысел | [Наш канон](our-canon.md) | 25:00, пять часов, чрезмерный набор устройств |

Начинать с действия персонажа. Затем выбирать один-два совместимых мема. Для шутки про аккумулятор достаточно занятой розетки и уверенного рассказчика; одновременно добавлять столешницу, коленку и юристов незачем.

У нового мема сохранять происхождение, варианты и сцену применения. Повторение вымышленной детали не превращает её в биографию.
