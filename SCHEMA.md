# Карточка сатирического материала

Цепочка: **эпизод → источник → противоречие → сцена → пародия**. Старые карточки сохраняют свои идентификаторы; при обновлении добавляются поля творческого применения.

```yaml
id: satire.topic.episode
title: Название
status: draft # draft | evidence_checked | satire_ready | needs_review
period: {from: YYYY-MM-DD, to: null}
claim_type: self_report
evidence:
  - url: https://example.org/post
    date: YYYY-MM-DD
    post_id: null
    summary: Что действительно сказано
    quote: null # только дословная проверенная выдержка
interpretation: Наше прочтение публичной манеры
comic_mechanism: Почему это смешно
neolurk_connection: Какой мотив сохранённой выжимки применён
scene: Вымышленное действие
parody_line: Вымышленная реплика, не цитата
uncertainties: []
counterexamples: []
related: []
updated: YYYY-MM-DD
```

## Тип фактической основы

- `verified_fact` — подтверждённый факт с источником.
- `self_report` — автор сообщает о себе; независимая проверка может отсутствовать.
- `direct_observation` — наблюдение над конкретным текстом или изображением.
- `interpretation` — наше объяснение наблюдений.
- `third_party_claim` — чужое утверждение с атрибуцией.
- `satire` — преувеличение или карикатура.
- `fictional_canon` — наша постоянная вымышленная деталь.

Источники и цитаты не переписываются ради шутки. Расхождения хранятся рядом, а не исправляются молча. Непроверенное остаётся непроверенным независимо от числа повторений в сатирических источниках.

## Учёт товаров

Поля события: дата, URL поста, модельное имя, вариант/комплектация, роль упоминания, происхождение рекомендации, заявление о личном использовании, уверенность сопоставления.

Роли: `recommendation`, `secondary_recommendation`, `background`, `different_variant`. Положительная оценка внутри другого блока считается отдельно от основного предложения. Происхождение: собственная рекомендация, пересказ читателя или не установлено. Читательское предложение исключается из авторского итога. Одна модель учитывается один раз в выпуске; аксессуар и другая комплектация не автоматически тот же товар. Факт оплаты требует отдельного подтверждения.

Материалы магазинов не открываем: используем сохранённые посты и текстовые URL как данные. Неизвестный точный артикул не восстанавливаем догадкой.
