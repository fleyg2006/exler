# Персонаж для сатиры

Разбираем публичную роль рассказчика: кто выносит вердикт, как он обосновывает свою правоту и что происходит, когда бытовая вещь не слушается эксперта.

- [Ядро образа](core.md) — драматургия уверенного обозревателя.
- [Самопрезентация](self-presentation.md) — авторство, субъективность и правила общения как материал для сцен.
- [Биографический фон](biography.md) — эпоха и профессия для правдоподобной обстановки.

Практический результат раздела — узнаваемая роль в пародии. Описание строится по публичным текстам; внутренние мотивы обозначаем как интерпретацию. Обобщение о характере не подменяет эпизод и источник. Медицинское досье для этой задачи не требуется.

Начинать с [Неолурка](../sources/neolurk-summary.md) и [нашего канона](../canon/our-canon.md). Проверенные товарные эпизоды — в [историях покупок](../research/products/PURCHASE_STORIES.md).
