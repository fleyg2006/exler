# Профиль личности

Раздел описывает относительно устойчивые свойства публичного образа.

## Файлы, которые предстоит наполнить

- `biography.md` — проверенная биография и география жизни.
- `appearance.md` — внешность по периодам, одежда, мимика, позы.
- `personality.md` — черты характера и степень уверенности выводов.
- `values.md` — заявленные ценности и их изменение.
- `health.md` — только публично сообщённые сведения о здоровье.
- `contradictions.md` — несовпадающие заявления и изменение позиций.
- `public-roles.md` — писатель, блогер, кинокритик, технообозреватель, эмигрант.

## Вопросы раздела
