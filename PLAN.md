# План продолжения проекта EXLER

Сохранён 2026-09-16 по просьбе пользователя. **План зафиксирован; товарный анализ приостановлен до следующего указания.** Отдельное поручение подготовить биографию выполняется сейчас.

## Исходное состояние

Проверенная выборка: 33 модельных имени, 92 упоминания, 82 положительные рекомендации/оценки. Это не полный рейтинг корпуса. Технический реестр охватывает 237 публикаций и 2587 разделов; 2244 блока остаются кандидатами для содержательной проверки.

## Порядок работы

1. **Разобрать 11 спорных блоков.** Отделить собственные рекомендации от читательских подсказок, советов знакомых и пересказов. Сохранить решение и его основание для каждого блока.
2. **Разметить оставшиеся товарные блоки по категориям.** Установить, что предлагается, сообщал ли автор о покупке и испытании, не упомянута ли вещь только для сравнения. Намерение купить не считать состоявшейся покупкой.
3. **Свести повторы.** Сопоставлять название, марку, модель, характеристики и комплектацию. Безымянные вещи не объединять по догадке; совпадение подписи ссылки не считать тождеством товара.
4. **Собрать общую сводку.** Количество собственных рекомендаций, подтверждённые разные модели, частота повторов, основные категории. Неразрешённые случаи и границы полноты показать отдельно; количество ссылок не выдавать за количество реклам.
5. **Пополнить сатирические сюжеты.** Повторные находки, смена аргументов, обещанные испытания и возвращение к прежним вещам. Использовать конкретные эпизоды, [выжимку Неолурка](sources/neolurk-summary.md) и [наш канон](canon/our-canon.md). Факты, интерпретации и выдумку разделять.

## Ограничения и сохранение

Работать по сохранённым публикациям и HTML. **Не заходить на AliExpress, не открывать товарные карточки, короткие ссылки и перенаправления.**

После каждого этапа сохранять результаты в Git, обновлять README и [статус исследования](research/products/STATUS.md). Не отмечать этап завершённым, если выполнен только автоматический или выборочный проход.
