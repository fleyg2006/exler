# Проект Ванга

Ошибочные прогнозы Алекса Экслера и случаи, которые на них похожи. Проверка: **21 сентября 2026 года**. Материал для сатиры на публичную экспертную уверенность.

**14 основных историй и 11 контекстных карточек — 25 разобранных эпизодов.** Среди основных есть точные числовые ошибки, несостоявшиеся сценарии, чрезмерно широкие технологические выводы и вероятностные прогнозы наград. Контекст включает пересказы чужих прогнозов, ретроспективные признания, частичные ошибки и мягкие предположения. Это не 25 одинаково доказанных провала и не статистика точности всех прогнозов автора.
