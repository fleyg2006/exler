# Доктор Худ: с фактами сложнее

Проверка книги Алекса Экслера «Похудеть — это просто», редакция 2018 года. Дата проверки: 29.09.2026.

**14 разборов книги: восемь фактических и терминологических неточностей, четыре чрезмерных обобщения, одна спорная подача медицинских данных и один редакторский дефект.** Отдельно — три проверки статьи 2023 года. Это разные по серьёзности замечания, не семнадцать доказанных опасных рекомендаций.

**Новое: [«Белок исчез, уверенность осталась»](FOLLOWUP.md)** — предел 30 г белка, завышенная белковость фасоли, пересмотр дробного питания, категоричность о тренировках и темпе похудения. В дополнении пять новых сатирических сцен.

Получен полный бесплатный EPUB с сайта автора. Для медицинских возражений использованы исследования и документы, существовавшие до выпуска книги; поздние пояснения автора отмечены отдельно. [Издание и метод проверки](METHOD.md).
