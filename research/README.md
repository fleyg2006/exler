# Исследование для сатиры

Исследование должно заканчиватьcя конкретным материалом: подсчётом, цепочкой событий, карточкой сцены или пародией.

## Приоритет: где Экслер накололся

[Отдельный раздел `failures/`](../failures/README.md): 114 карточек неудачных покупок, расходов, бытовых ошибок и публичных исправлений. 94 основные истории и 20 небольших эпизодов. Есть [источники](../failures/SOURCES.md), [годовой проход по Культу и исследование сайта](../failures/COVERAGE.md), [открытые наводки](../failures/LEADS.md) и [комические конструкции](../failures/SATIRE.md). Добавлен [старый архив и три года Культа](../failures/OLDER.md): 59 новых карточек. Работа выполнена по отдельному поручению пользователя; сохранённый общий товарный план остаётся отдельной задачей.

Следующий проход — разметка происхождения рекомендаций и роли каждого товарного блока. Собственное предложение, пересказ читателя, сравнение, владение и заказ должны различаться. АлиExpress не открываем; сомнительную модель оставляем несопоставленной.

Новые темы — кино, бытовые жалобы, правила площадки — брать небольшими датированными выборками. Одна сцена может опираться на один эпизод; для обобщения о повторяющейся манере требуются несколько примеров.

Статусы материала: `draft`, `evidence_checked`, `satire_ready`, `needs_review`. Проверка источника и качество шутки — две отдельные задачи.
