# Очередь исследования

## Первый проход

- собрать официальную биографию и хронологию;
- составить каталог книг и основных рубрик сайта;
- выбрать репрезентативные тексты разных лет;
- построить реальный частотный словарь;
- выделить устойчивые поведенческие сценарии;
- проверить происхождение старых мемов;
- собрать визуальные референсы по периодам;
- отделить автора от персонажей его книг;
- описать Игоря и Сергея;
- заполнить пробелы в Неолурк-конспекте первичными ссылками.

## Статусы

`todo`, `collecting`, `verified`, `disputed`, `done`.
