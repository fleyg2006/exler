Следующий проход — разметка происхождения рекомендаций и роли каждого товарного блока. Собственное предложение, пересказ читателя, сравнение, владение и заказ должны различаться. АлиExpress не открываем; сомнительную модель оставляем несопоставленной.

Новые темы — кино, бытовые жалобы, правила площадки — брать небольшими датированными выборками. Одна сцена может опираться на один эпизод; для обобщения о повторяющейся манере требуются несколько примеров.

Статусы материала: `draft`, `evidence_checked`, `satire_ready`, `needs_review`. Проверка источника и качество шутки — две отдельные задачи.
