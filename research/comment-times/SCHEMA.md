# Данные и воспроизведение

`observations.jsonl`: по одному ответу на строку. `thread` ссылается на `id` в `threads.jsonl`; `time` — отображаемая минута без часового пояса. `origin` различает текущий HTML и архивную метку. `own_text_sha256` — сумма нормализованного собственного текста после удаления структурных цитат. `severity` 0/1/2, у четырёх архивных записей `null`; `moderation` — отдельный категориальный код. `parent_present` отражает наличие родительской реплики в текущем HTML, не её корректность.

`threads.jsonl`: адрес, название, дата поста, принадлежность к ленте или старым веткам, статус ответа, время получения, SHA-256 исходного HTML, счётчики. `daily.json` — 184 дня; `tails.json` и `returns.json` — цепочки с первичными ссылками и публикациями между метками. `review-design.json` описывает шкалу и последовательность чтения.

Из корня этого раздела:

```bash
python reproduce.py
python render_chart.py
```

Нужны Python 3, NumPy, Matplotlib; для повторной загрузки — lxml. Публикационная база берётся из `../publication-times/publications.json`. `collect.py --workers 4` повторно получает выбранные страницы, сохраняя локальный кэш; `--retry` повторяет только неудачные запросы. Разметка текста не генерируется словарём автоматически и сохраняется отдельно от повторного сбора.

Метки 1 и 2 не означают, что читатель прав, бан несправедлив или автор испытывал определённую эмоцию. Нулевая метка — отсутствие ясного признака по выбранной шкале, а не сертификат вежливости.
