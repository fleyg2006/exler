# Исследование товаров: незавершённый первый проход

Дата: 2026-09-15.

Задача пользователя: только рекомендации Алекса, без рекомендаций читателей; общее число рекомендаций, уникальные товары, повторы одинаковых моделей, категории, условный психологический профиль с доказательствами. Не диагностировать психические расстройства по рекламе.

## Полученные данные

Запрос posts с q=Делимся находками, limit=250 вернул 240 записей, next_after_id=null. Период: 2021-05-23 — 2026-06-14. Текст body заполнен во всех 240 записях. Среди них 236 обычных выпусков Ali и один выпуск главной распродажи года; три записи являются служебными (ID 2478, 3488, 9264), а не товарными подборками.

Запрос всех HTML сразу вернул пустое тело ответа. Порционная загрузка по пять записей получила 120 записей, в том числе 118 выпусков Ali, после чего выполнение остановлено сообщением среды: network approval was cancelled before a decision was returned. Не обходить этот отказ; продолжение сетевой выгрузки требует прояснения доступа.

## Скрипты

fetch_product_html.py: читает локальный exler-products-page1.json, загружает порции HTML в html_batches/. Ключ берёт исключительно из переменной EXLER_API_TOKEN. В репозитории секрета нет.

analyze_products.py: экспериментальный извлекатель ссылок из авторской части публикаций. Результаты в product_analysis/. Это ещё не готовый подсчёт товаров.

## Обязательные исправления перед выводами

1. Одна позиция может иметь отдельные ссылки для РФ и других стран — объединять, а не считать дважды.
2. Одинаковая модель может иметь разные короткие партнёрские URL в разных выпусках. Число уникальных ссылок НЕ равно числу уникальных товаров.
3. Правила категорий пока грубые: классификацию необходимо проверить вручную, включая перенос контекста с основного описания на региональную ссылку.
4. Один раздел между hr может содержать несколько разных товаров. Нельзя механически приравнять раздел к товару.
5. Личные утверждения о покупке/использовании относить к конкретному товару, не ко всему разделу без проверки.
6. Комментарии Alex Exler сверять с exler_comments: автор в HTML может иметь дополнительную разметку, а цитаты читателей должны исключаться. Текущий HTML-парсер комментариев не валидирован.
7. Общие ссылки на распродажи и магазины не считать товарами.
8. Удалять параметры трекинга при нормализации URL, сохраняя исходную ссылку отдельно.

Итоговая статистика, рейтинг повторов и психологический профиль пока НЕ готовы. Не использовать промежуточные количества ссылок как результаты исследования.
