# Товарные подборки: состояние исследования

Обновлено 2026-09-15.

Полностью загружены HTML всех 240 найденных записей. Из них 237 товарных выпусков за 2021-05-23 — 2026-06-14; три служебные записи исключены. Загрузка возобновлена после подтверждения пользователя и завершена. Пропущенных HTML среди выпусков нет.

## Полученные результаты

[STYLE_FINDINGS.md](STYLE_FINDINGS.md) — первый разбор манеры письма, шесть источников-примеров, частоты словесных маркеров, условный портрет публичной потребительской подачи и контрпримеры. [style_markers.json](style_markers.json) — проверяемые списки ID совпавших выпусков. build_style_notes.py воспроизводит их из результата analyze_products.py; запускать из каталога research/products после загрузки корпуса и извлечения ссылок.

Извлекатель получил 2712 строк товарных ссылок после фильтрации, 2660 разных нормализованных адресов, 2308 разделов между разделителями с найденными ссылками. ## Что ещё требуется для товарного рейтинга

1. Разметить роль каждой модели: рекомендация, собственное использование, сравнение, прежняя покупка, альтернатива.
2. Объединить модели по названию и характеристикам, не по короткому URL; варианты и неустановленные совпадения сохранить отдельно.
3. Проверить категории вручную. Экспериментальные категории в stats.json пока непригодны для выводов: например, подстрока «вина» может совпасть внутри другого слова.
4. Проверить остаточные дубли региональных ссылок и ссылки без товарного назначения.
5. Авторские комментарии сверить с таблицей exler_comments перед добавлением в подсчёт. В анализ манеры письма комментарии не включались.

Рейтинг одинаковых товаров и итоговое количество рекомендаций пока не установлены. Психиатрические диагнозы по публикациям не делаются. Повторное упоминание не доказывает оплаченную рекламу.

## Данные и воспроизводимость

fetch_product_html.py получает HTML порциями по пять записей, ключ только из EXLER_API_TOKEN. Исходный список exler-products-page1.json — результат action=posts, q=Делимся находками, limit=250, include_body=1; next_after_id=null. HTML сохраняются в html_batches, извлечение — в product_analysis. Исходные выгрузки локальные и не включены в репозиторий: повторный запуск требует доступа к шлюзу. Секреты не публикуются.
