# Обзор будет, но не будет

Обещанные обзоры, статьи и продолжения, которые автор признал несделанными или выполнение которых не найдено при проверке. Проверено 21 сентября 2026 года.

| История | Статус |
|---|---|
| [Cupra Formentor](CASES.md#unfulfilled-001) | Обещание 20.03.2023, повтор 24.04.2023; отдельный обзор не найден |
| [Synology DS920+](CASES.md#unfulfilled-002) | После анонса автор объяснил, что обзор не сделал и возвращаться к устаревшей модели не видит смысла |
| [POCO C40](CASES.md#unfulfilled-003) | После анонса прямо сообщил о решении не выпускать обзор |
| [Logitech Brio](CASES.md#unfulfilled-004) | Есть позднее объяснение отказа; Stream Edition/Pro требуют оговорки |
| [Музей Vivanco](CASES.md#unfulfilled-005) | Общий отчёт о Риохе вышел, отдельная музейная статья обещана повторно и не найдена |
| [Laurent-Perrier](CASES.md#unfulfilled-006) | Обещанная статья о посещении и дегустации не найдена |
| [История Дюпонов](CASES.md#unfulfilled-007) | Обещание без срока; отдельный материал не найден |

Всего семь историй: два собственных подтверждения отказа, одна связка с оговоркой о модели, четыре поиска без найденного выполнения. Причины отказов сохранены; отсутствие результата в поиске не приравнено к доказательству умышленного обмана.
