Главный повторяющийся механизм — **усиление по дороге от источника к выводу**. Гипотеза получает более окончательный заголовок; наблюдение в выборке расширяется до населения; условие эксперимента выпадает из короткого пересказа. Иногда усиление уже есть у посредника, как в материале BBC: тогда его нельзя объявлять самостоятельным изобретением блогера.

Поправки — полноценная часть результата. В шести цепочках они сохранены рядом с первоначальной подачей. Поэтому вывод «никогда не исправляет» эти материалы не поддерживают. При этом исправленный текст позволяет изучить, какой вердикт успел возникнуть до уточнения.

Для дальнейшей сатиры особенно удобны [исчезнувшая кнопка](CASES.md#src-001), [винный эксперимент без контрольной группы](CASES.md#src-002) и [перепутанные адреса сервисов](CASES.md#src-010). Последняя история уже была в CHAIN-001: здесь добавлен разбор ошибки идентификации, а не ещё один случай.
